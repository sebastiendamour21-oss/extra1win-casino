EXTRA 1WIN - Cloudflare Worker

Contenu :
- src/index.js : code du Worker
- wrangler.toml : configuration du Worker et liaison D1 Db
- package.json : commande de déploiement

IMPORTANT :
1. La liaison D1 doit s'appeler exactement Db (D majuscule).
2. Le code fournit une API d'inscription, d'analyse statistique descriptive,
   de lecture des résultats et d'ingestion protégée.
3. Aucun flux officiel 1win n'est connecté. Les résultats doivent être fournis
   par une source autorisée. Les statistiques ne prédisent pas les résultats.
4. Avant toute utilisation publique, il faudra configurer un secret
   INGEST_API_KEY dans Cloudflare.
5. Déploiement depuis un environnement compatible Node :
   npm install
   npm run deploy
